# Demo products on the Transformer cell

- `angle_grinder/`, `battery_replacement/`: the product folders of Case 1 and Case 2 (see their READMEs).
- `transformer_cell.json`: the **cell file** of the real Transformer cell. As decided in #132, Robot 1 grips and inserts (places the lid), and Robot 2 screws in (screwdriver, bit `H5`) and inspects (`zivid`). Robot 2's EGU gripper is left out, so that B1 does not give it an insertion. For remanufacturing (#277) both files also have the DMG DMU 60 as a machine offering rework milling, the pallet storage next to the cell door, one pallet (on the pallet storage at the start, `locations`) and the Pizzagreifer as a tool of Robot 1 for loading, unloading and reconfiguring; `notes` says which poses are estimated or placeholders.
- `transformer_cell_simulation.json`: the same file plus a screwdriver on Robot 1, so that both robots may screw the battery at the same time in the cell simulation (#151). It sets `"simulation_only": true` (#236): the run controller refuses a run that targets the real cell with this file, so a run on the cell cannot pick up Robot 1's screwdriver. The flag defaults to false when a file does not set it. The sequence graph exports record no cell file: load them with either one.

Keep the two files in step: they differ only in Robot 1's tools and capabilities, in the supply station and slot poses, and in the screw nest plates: the simulation's file has one H5 nest plate per robot (a slot's `robots` names the robots it serves), so that both robots fetch screws at the same time (#151). The real cell has one nest plate; how two robots share it is open (#251). Known placeholders:
- **Station poses** are all zero until the stations are measured, except the simulation's supply station. The supply slots sit in the supply station, their poses relative to it (AT 174); `mrtamp.supply.slots_in_cell_frame` gives them in the cell frame.
- **Supply slot poses** are all zero in the real cell's file until the screw nest plate (#42) and the part supply are measured. The simulation's file has nominal poses that the robots they serve reach in the cell simulation (#151), not measured ones: its supply station stands at the crown gear slot (-1.2, -2.6, 0.8), so the cell-frame poses are the same as before the slots moved into the station. The fixture pose of the sim runs is a placeholder in `examples/mrtamp_demo_runs.py`.
- **Descriptions** (element name to URDF file) are empty in both files until the URDFs are in the repository.
- **Times** are in each cell file's **travel-time table**, the file next to it named `<cell file name>.travel_times.json` (ADR-0012, AT 174), and the cell's fingerprint covers both files. Until #235 reshapes the table, it holds the `default_cell_settings()` values (feed rates and offsets included) plus a nominal `inspection_time` of 10 s, under `"times"`. A cell file that still holds `cell.timing` is refused.
- **Tool names** follow the sequence graph steps: `H5` is the screw head the screwdriver serves, and `default_gripper` stands for the EGU gripper.

Sequence graph exports: `python examples/export_demo_products.py` (see that script). Assembly runs of both products in the cell simulation: `python examples/mrtamp_demo_runs.py` (see that script for starting the simulation).
