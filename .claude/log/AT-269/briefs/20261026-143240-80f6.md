## Summary
AT 269 makes sequence graph extraction stop at the disassembled states (every target part removed) unless a full teardown is asked for. The line-balancing example script builds its graph with the default and then, with its default `--goal full`, balances "the cheapest-to-reach, most-fully-disassembled state (fewest parts_present) -- balances the whole teardown line". With the new default, that state would silently be a disassembled state for any product whose target parts are not the last to come out, so "full" would no longer be full. The interim answer extracts a full teardown when `--goal full` is chosen and keeps the default for `--goal target`. The answer "no" would leave the script as it is, and its "full" goal would depend on the product's target parts. Only this example script changes; the line-balancing module itself is untouched, as the ticket asks.
