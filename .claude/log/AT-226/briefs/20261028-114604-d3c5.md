Which part should the converter set as the base part, and which as target parts, in the product setup it writes?
I recommend the part with the largest bounding box as base and every other part as target, because the dataset names no base and the largest body is the one the others are assembled onto.

## Summary
AT 226 builds a script that turns an Assemble-Them-All assembly into a planner-ready product folder. The product setup file of such a folder must name base parts and target parts, but the dataset says nothing about either; the script's draft writes `{"base_parts": ["part_0"], "target_parts": ["part_1", "part_2"]}`, picking the part with the largest bounding box as base. A `--base` option overrides the choice per assembly. If the answer is another rule (for instance part 0 as base, or a hand-picked list per benchmark product), only that one function and its test change. The benchmark selection of the 3 to 5 products will review the choice per product anyway.
