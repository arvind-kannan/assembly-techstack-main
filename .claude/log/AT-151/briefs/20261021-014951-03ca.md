Which NC programs should the milestone runs save, given that the cell simulation writes NC only for a run on the real cell?
I recommend a second, cell-targeted rehearsal of each product with the real cell's cell file against the offline simulation, because it needs no code change and keeps NC programs away from the simulation-only tools.

## Background
The cell simulation answers each operation plan with a simulation report. The report carries the two NC programs (one per robot, Sinumerik text) only when the run's target is the real cell: `"nc_programs": self._nc_programs() if target == "cell" ...`. A run targeted at the simulation gets none.
There are two cell files. The real one has Robot 2 alone screwing. The simulation file adds a screwdriver on Robot 1, so both robots may screw the battery, and it is flagged simulation-only: the run controller refuses a cell-targeted run with it (the simulation-only cell file build, AT 236).

## Scenario
The battery run uses the simulation file. Both robots screw. The report has no NC programs. Asking for NC with the target "cell" is refused before planning, by design.

## Why this came up
The ticket's "Done when" asks for a simulation-targeted run whose plan, report and NC programs are saved. In the current code, these three cannot all hold for the battery. AT 236 and ADR-0008 (no unchecked motion to the cell; NC only from the simulation) made the refusal on purpose.
