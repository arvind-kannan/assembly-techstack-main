## Summary
AT 233 builds an operation-plan builder that the v1 and B1 planners both use to record their chosen steps and finish them into an operation plan. The ticket says the B1 tests test past the planner's interface: today their helper `spans_of` calls `nominal_schedule(plan.operations, req.cell, req.start_snapshot.cell_state.mounted_tools, plan.sync_points)` and digs the operation rows out of its list of dicts. The build adds `operation_spans(plan, cell)` in the nominal-schedule module, which reads the start tools and sync points from the plan itself and returns each operation's start and end; `spans_of` now calls it. The other answer would be to drop span assertions from the B1 tests altogether, or to add a timeline to the operation plan, which is core model and out of scope. Only the tests and the new helper are affected; no other ticket uses the name yet.
