## Summary
AT 277 lets the model-level stand-in check loading, unloading, reconfiguring and machine operations. The closed reason-code list today has `unsupported_process` and `cell_state_mismatch`, among others. The build maps "robot lacks the capability", "its tool grips none of the item's interfaces" and "the station does not offer the process" to `unsupported_process`, and "coupling place does not accept the item", "is occupied", "item not where expected" and "no pallet in the machine" to `cell_state_mismatch`, each with its own text. New codes would let a replanner react per case, but would change the core feedback list, which the approved scope (processes and cell state) does not cover. Adding codes later changes one table in the stand-in and the tests.
