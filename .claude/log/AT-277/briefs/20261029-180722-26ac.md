Where does the cell file say that a pose is estimated or a placeholder, and where the pallet stands at the start?
I recommend two optional keys of the cell file (not the core cell): "notes" by element name, and "locations" for where each pallet and tooling is at the start, next to the mounted tools.

## Summary
AT 277 adds the DMG (pose estimated), the pallet storage (pose a placeholder) and a pallet to the Transformer cell file. JSON has no comments, the core station has no note field, and saving a cell file drops unknown keys, so the marks need a place. The build adds "notes" (element name to text) and "locations" (pallet or tooling name to its start location, like "mounted_tools" for tools) to the cell file loader in the MRTAMP app; both are left out when empty, so other cell files keep their JSON. A start location in the cell file means a run can begin from it; the examples do not read it yet.
