S · Product explorer mesh update · blocks where a changed mesh file is written inside the product folder · undo: a rename of a folder name
Where should the new mesh of a changed part be written in the product folder?
I recommend a new folder next to the meshes (update-1, update-2, ...) that keeps the file name, because undo reloads the old mesh from its old path and matching by file name must keep working.
## Summary
AT 244 replaces the mesh of a part whose CAD file changed, and the whole update is one undoable edit.
The product model reloads each mesh from its path whenever it is copied, so overwriting "tiny_test_product/01_base.stl" would make an undone state load the new mesh as soon as another edit happens.
A new file under "tiny_test_product/update-1/01_base.stl" keeps the old file reachable and keeps the file name, which the next update matches on.
The cost is old mesh files left behind in the product folder, as the merge edit already does after an undo.
The other answer is a backup copy of the old file with the history repointed to it; that moves the old mesh instead of the new one, but touches every earlier state.
