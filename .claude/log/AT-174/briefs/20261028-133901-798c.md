Which rotation order do the pose angles rx, ry, rz follow when a supply slot's pose is composed with its station's pose?
I recommend fixed-axis x, then y, then z (roll, pitch, yaw), because the cell simulation's code already reads Euler angles that way (pybullet's convention).

## Summary
AT 174 moves supply slots into the supply station; a slot's pose becomes relative to the station, as decided in AT 122.
Planners need the slot in the cell frame, so the build composes the station pose with the slot pose.
Today no cell file rotates a station, so every answer gives the same result for the existing cell files; the convention only matters once a station is rotated.
The convention is written in the core's docstring for the pose and used by one helper in the MRTAMP app; changing it later is one line plus that docstring.
