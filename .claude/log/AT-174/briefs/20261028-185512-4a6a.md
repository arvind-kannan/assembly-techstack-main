## Summary
AT 174 moves the cell's times out of the cell file into a travel-time table file next to it, as decided on card 157c (option A). Neither ADR 0012 nor AT 235, the travel-time table build, names that file. Today the transformer cell's file `cases/transformer_cell.json` holds `"timing": {"toolchange_time_at_toolstorage": 60.0, "inspection_time": 10.0, ...}`. After the build, `cases/transformer_cell.travel_times.json` holds `{"times": {"toolchange_time_at_toolstorage": 60.0, "inspection_time": 10.0, ...}}`, and the cell file loader reads it with the cell file. Another name changes only the loader and three data files; AT 235 then reshapes the content of the same file.
