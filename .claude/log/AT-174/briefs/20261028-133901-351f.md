Does the closed list of interfaces get a fourth value for zero-point clamping?
I recommend yes, a value `zero_point_clamping`, because the DMG table's coupling place accepts the pallet through it and accepts nothing else.

## Summary
AT 174 adds stations with coupling places to the core cell; each coupling place names the one interface it accepts.
The glossary says: "The cell has three: the SWS (...), the finger interface (...) and the Schunk NSR-A (...); a pallet also has zero-point clamping towards the machine."
With three values only, the zero-point receiver on the DMG table cannot be described, so the build adds `zero_point_clamping` as a fourth value of the interface list.
If the answer is no, the value is removed again and the DMG coupling place needs another way to state what it accepts; no cell file lists a machine yet, so nothing else changes.
